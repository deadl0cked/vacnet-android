# История изменений / Changelog

## 1.1 preview — 6 октября 2026

- Мобильная раскладка нового дизайна VACnet: видео и ответы в одной колонке, без горизонтального обрезания.
- Полоса перемотки отдельно от кнопок плеера; доступные и заблокированные ответы сохраняют поведение сайта.
- «Обновление приложения» в настройках: автоматическая и ручная проверка GitHub, скачивание APK по нажатию.
- Красный индикатор у настроек при наличии более новой сборки.
- Прежние имя пакета и подпись: версия устанавливается поверх 1.0. Номер сборки Android — 2.

[Скачать 1.1 preview](https://github.com/deadl0cked/vacnet-android/raw/refs/heads/main/downloads/VACnet-1.1-preview.apk) · [SHA-256](downloads/SHA256SUMS.txt).

Сборка и Android Lint проходят без ошибок. Проверка обновлений покрыта модульными тестами. Раскладка проверена на воспроизведённой структуре нового дизайна с официальным CSS на ширинах 320, 364, 412 и 800 px, включая перенос экрана и перерисовку. Проверка авторизованного портала на физическом телефоне при подготовке этой версии не проводилась.

Это предварительная debug-сборка. Демонстрационный ролик в README относится к версии 1.0.
