# Third-party components

VACnet uses Android platform APIs and the following libraries declared by the local project:

| Component | Version | License |
| --- | --- | --- |
| AndroidX Core KTX | 1.13.1 | Apache License 2.0 |
| AndroidX AppCompat | 1.7.0 | Apache License 2.0 |
| AndroidX SwipeRefreshLayout | 1.1.0 | Apache License 2.0 |
| AndroidX Browser | 1.8.0 | Apache License 2.0 |
| Material Components for Android | 1.12.0 | Apache License 2.0 |
| Kotlin standard library | 2.0.21 | Apache License 2.0 |

Additional dependencies include AndroidX libraries, Kotlin coroutines, JetBrains annotations and Guava ListenableFuture. The dependency catalog and license names from their local Maven POMs are listed in [licenses/components.txt](licenses/components.txt). The full Apache License 2.0 is included in [licenses/Apache-2.0.txt](licenses/Apache-2.0.txt). Results of scanning the local dependency archives for standalone notice files are recorded in [licenses/upstream-notices.txt](licenses/upstream-notices.txt).

- [AndroidX source and license](https://android.googlesource.com/platform/frameworks/support/)
- [Material Components source and license](https://github.com/material-components/material-components-android)
- [Kotlin source and license](https://github.com/JetBrains/kotlin)

The third-party libraries’ license grants are independent of the rights reserved for the application’s original code. The Valve portal, its video player and other website resources are loaded from the website, rather than being granted a license by this repository.
